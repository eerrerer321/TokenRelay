模型與價格

模型名稱類型輸入（美元 / 100 萬 tokens）快取命中的輸入輸出（美元 / 100 萬 tokens）單次輸出上限圖片

每次請求會先預扣「最壞情況」的費用，回應結束後按實際 token 數多退少補，所以餘額要比單次費用多一些才能發出請求。

「快取命中的輸入」：長對話或 agent 每次都會重送前面的內容，上游認出重複的部分時會回報「快取命中」，這部分改用較低的價格。 能不能命中由上游決定；上游沒回報就照一般輸入價。

「產生圖片」按張數收費（/v1/images/generations）；「文字轉語音」按輸入的字元數收費（/v1/audio/speech）； 「embeddings」只收輸入（/v1/embeddings）。
