# 部署：家裡的 Windows 電腦 + win-acme 自動續簽 HTTPS

做法跟公司 PCC（pcc.youparking.com.tw）一樣用 win-acme 向 Let's Encrypt 申請免費憑證、自動續簽。
差別：PCC 多半是把憑證裝進 IIS；這裡不需要 IIS，win-acme 把憑證**存成 PEM 檔**，轉發站自己讀。

```
朋友的電腦 ──HTTPS 443──▶ 路由器 ──轉發──▶ 這台 Windows：python -m app.serve
                                              ├─ 0.0.0.0:443   對外，HTTPS（win-acme 的憑證）
                                              └─ 127.0.0.1:8000 只有本機，後台 /admin
```

## 0. 先準備

| 項目 | 說明 |
|---|---|
| 網域 | 例如 `relay.example.com`，DNS 的 A 紀錄指到家裡的對外 IP。家裡 IP 會變的話要用 DDNS（動態 DNS）服務自動更新 |
| 路由器 | 把 TCP **443**（朋友連線）和 **80**（win-acme 驗證網域用）轉發到這台電腦的內網 IP。內網 IP 要固定（在路由器設 DHCP 保留） |
| 不要轉發 | **8000**（後台）。後台雖然也會檢查是不是本機，但不需要的門就不要開 |
| ISP | 有些網路業者會擋家用網路的 80 / 443 進線。被擋的話 win-acme 改用 DNS 驗證，朋友改用其他埠（`https_port`） |

## 1. 安裝與設定

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy config.example.ini config.ini
```

`config.ini` 照註解填好（邀請碼、上游 key、收款地址…），`[site] public_url` 填 `https://relay.example.com`。
`[server]` 先設 `https_port = 0`（還沒有憑證），用下面的指令確認能啟動，再開 http://localhost:8000/admin 看後台：

```powershell
python -m app.serve
```

## 2. win-acme 申請憑證

1. 到 win-acme 官網下載（跟 PCC 用的同一個工具），解壓縮到例如 `C:\tools\win-acme`。
2. **用系統管理員身分**開 PowerShell，執行（網域、email、資料夾換成你的）：

   ```powershell
   C:\tools\win-acme\wacs.exe --source manual --host relay.example.com --validation selfhosting --store pemfiles --pemfilespath C:\certs\relay --accepttos --emailaddress 你的email
   ```

   - `--validation selfhosting`：驗證時 win-acme 自己在 80 埠回答 Let's Encrypt 的問題，所以 80 要轉發進來
   - `--store pemfiles`：存成 PEM 檔，資料夾裡會有 `relay.example.com-chain.pem`（憑證 + 中繼憑證）和
     `relay.example.com-key.pem`（私鑰）
   - win-acme 會自己建立每天檢查的排程，快到期就自動續簽（跟 PCC 那邊一樣）
   - 參數名稱以你下載的版本為準：`wacs.exe --help` 可以查。也可以不加參數執行，用互動選單一步步選
3. `config.ini` 的 `[server]` 填上：

   ```ini
   [server]
   https_port = 443
   ssl_certfile = C:\certs\relay\relay.example.com-chain.pem
   ssl_keyfile = C:\certs\relay\relay.example.com-key.pem
   ```

> 私鑰（`-key.pem`）跟上游 key 一樣不能外流：不要放進專案資料夾、不要上傳。

續簽後**不用重啟**：伺服器每小時檢查一次憑證檔，有變就自動換上新憑證（紀錄裡會出現「已換上新的 HTTPS 憑證」）。

## 3. 開機自動啟動、每天備份

用系統管理員身分在專案資料夾執行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install-tasks.ps1
Start-ScheduledTask -TaskName "AI Relay"
```

它會建立：

| 工作排程 | 做什麼 |
|---|---|
| AI Relay | 開機就啟動（不用登入 Windows）；異常結束時每分鐘自動重啟。紀錄在 `logs\` |
| AI Relay Backup | 每天 04:00 用 `python -m app.cli backup` 備份資料庫到 `backups\`，留最新 14 份 |

還有一條防火牆規則「AI Relay HTTPS」開放 443。

> 備份檔放在同一台電腦，電腦壞了一起沒。建議偶爾把 `backups\` 最新一份複製到別的地方（隨身碟、雲端硬碟要加密）。
> 備份裡有使用者 email、密碼雜湊和帳本，不要公開。

## 4. 確認

- 用手機關掉 Wi-Fi（走行動網路）開 `https://relay.example.com/health`，看到 `{"ok":true}`，瀏覽器沒有憑證警告
- 這台電腦開 http://localhost:8000/admin 看得到後台；手機開 `https://relay.example.com/admin` 要是 404
- 重新開機後不用登入，手機一樣連得到

## 5. 日常

| 要做的事 | 怎麼做 |
|---|---|
| 改價格、開關模型 | 後台 http://localhost:8000/admin（直接寫回 config.ini，不用重啟） |
| 改其他設定（邀請碼、收款地址…） | 編輯 config.ini，然後 `Stop-ScheduledTask "AI Relay"; Start-ScheduledTask "AI Relay"` |
| 朋友忘記密碼 | 後台 → 使用者 → 重設密碼連結，私訊給他 |
| 看紀錄 | `logs\relay-*.err.log`（Python 的紀錄都在這個檔） |
| 從備份還原 | 停掉 AI Relay → 把 `backups\` 裡的檔案複製回 `config.ini` 的 `database_url` 指的位置 → 啟動 |
